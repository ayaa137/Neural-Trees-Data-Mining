About the Project

Project Overview

Traditional decision trees are easy to interpret but rely on discrete split decisions. Neural networks are highly flexible but often provide less transparent decision structures. Neural Trees attempt to combine advantages from both approaches by replacing hard tree splits with differentiable soft-routing decisions that can be optimized using gradient descent.

Research Question

How effectively can differentiable Neural Trees and Neural Tree boosting approaches perform across different classification and regression datasets, and how do they compare with established machine learning models for tabular data?

Methodology

Analysis Approach

🧹

Data Preparation

Each dataset was cleaned, encoded, split into training and test sets, and transformed into a suitable numerical representation. Continuous inputs were standardized where appropriate.

🌳

Differentiable Neural Trees

Hard binary decision nodes were replaced with trainable sigmoid split functions, enabling routing probabilities and leaf values to be optimized using gradient descent.

🚀

Boosting Strategies

Joint and Greedy Neural Boosting were implemented to evaluate whether combining multiple Neural Trees improves performance over a single differentiable tree.

📊

Model Evaluation

Classification models were evaluated using accuracy and weighted F1 score. Regression models were evaluated using MSE, RMSE, and R².

Soft Split Function

s(x) = sigmoid(w · x + b)

Each internal node produces a probability rather than a hard left or right decision. Leaf probabilities are obtained from the product of routing probabilities along each tree path.

Explainability

Interpreting Neural Trees

Neural Trees provide more than predictive outputs. Their differentiable tree structure makes it possible to inspect how features contribute to routing decisions and how observations move toward different leaves.

Feature Importance

Learned split parameters can be examined to identify which input variables contribute most strongly to the Neural Tree's decisions.

Split Weight Heatmaps

Split weights show how different features influence the internal routing nodes of the differentiable tree.

Leaf Probabilities

Soft routing creates probabilities over leaves rather than forcing observations into a single branch immediately.

Confusion Matrices

Classification confusion matrices help identify where models correctly distinguish classes and where prediction errors remain.

Insights

Main Findings

🌳 Neural Trees Provide a Differentiable Tree Architecture

Soft routing allows tree decisions to be optimized through gradient descent while retaining recognizable split and leaf structures.

🚀 Boosting Often Improves a Single Neural Tree

Joint and Greedy Neural Boosting frequently produced stronger results than the Single Neural Tree by increasing model capacity and combining multiple trees.

📊 Classical Models Remain Strong on Tabular Data

Random Forest, Gradient Boosting, and linear models remained highly competitive, with classical methods achieving the best overall results on most evaluated datasets.

🔎 Interpretability Is an Important Neural Tree Advantage

Feature importance, split weights, routing probabilities, and leaf behavior provide useful ways to examine how Neural Trees construct their predictions.

Critical Evaluation

Limitations

Regression Performance

Neural Tree regression performance remained weaker than the strongest classical baselines, particularly on Student Performance.

Hyperparameter Sensitivity

Neural models can be sensitive to tree depth, learning rate, training duration, initialization, and ensemble size.

Dataset Differences

The six datasets vary substantially in feature structure, sample size, preprocessing requirements, and target complexity.

Experimental Scope

The study provides a comparative implementation rather than an exhaustive optimization of every Neural Tree configuration.

Conclusion

Final Interpretation

The project demonstrates that differentiable Neural Trees can be implemented and evaluated within the same experimental framework as traditional tabular machine learning methods. Classical baselines remain the strongest practical choice on several of the evaluated tasks, particularly regression, but Neural Trees provide a valuable research-oriented alternative that combines neural optimization with transparent tree routing.


The boosted Neural Tree variants show that ensemble strategies can improve performance over a single tree, while the model structure supports interpretation through split weights, feature importance, routing probabilities, and leaf predictions.
