About the Project

Project Overview

Neural Trees combine the hierarchical decision-making structure of decision trees with differentiable neural-network optimization. Instead of using hard binary decisions at each node, Neural Trees use soft probabilistic splits that can be optimized using gradient descent.

This project investigates whether Neural Trees can provide competitive performance on structured tabular datasets while preserving a more interpretable tree-based architecture.

Three Neural Tree approaches were evaluated: Single Neural Tree, Joint Neural Boosting, and Greedy Neural Boosting.

Their performance was compared with established baselines including Logistic or Linear Regression, Random Forest, and Gradient Boosting. The study covers both classification and regression tasks.

Methodology

Neural Tree Approaches

🌳

Single Neural Tree

A differentiable decision-tree model using soft split functions and trainable leaf predictions optimized through gradient descent.

🔗

Joint Neural Boosting

Multiple Neural Trees are trained jointly, allowing the ensemble to optimize its predictions together as one differentiable model.

🚀

Greedy Neural Boosting

Neural Trees are added sequentially so that each new tree focuses on correcting prediction errors made by the existing ensemble.

Best Results

Best Classification Performance

96.67%

The strongest classification performance was achieved on the Iris dataset by Random Forest and Gradient Boosting. Breast Cancer WDBC also reached approximately 96.49% accuracy with Logistic Regression, Random Forest, and Gradient Boosting.

Best Regression Performance

R² = 0.8068

Gradient Boosting produced the strongest Student Performance regression result with an RMSE of approximately 1.99. Classical models remained stronger than the Neural Tree approaches on the regression datasets.

Insights

Main Findings

🌳 Neural Trees Are Competitive

Neural Tree methods demonstrated meaningful predictive ability, particularly on classification problems, while retaining a differentiable tree structure.

🚀 Boosting Helps

Joint and Greedy Neural Boosting frequently improved upon the Single Neural Tree by increasing model capacity and combining information from multiple trees.

📊 Classical Models Stay Strong

Random Forest and Gradient Boosting remained very strong reference models, particularly for regression tasks and traditional tabular machine learning problems.

Model Comparison Summary

The experiments show that there is no single model that dominates every dataset.

Gradient Boosting produced the strongest results for Adult Income, Bank Marketing, and Student Performance. Random Forest performed especially well on Iris, while Logistic Regression achieved excellent results on Breast Cancer WDBC.

Neural Trees provide a different advantage: they combine tree-based reasoning with neural optimization. Their soft routing structure makes it possible to train decision paths using gradient descent while still examining features, split weights, leaf probabilities, and model behavior.
